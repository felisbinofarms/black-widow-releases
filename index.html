Why Black Widow?

🔗

Transaction Grouping

Groups all 13 logs from one button click into a single view — see the complete chain, not just one file.

⏱️

Phase Detection

Separates backend time (triggers, flows, callouts) from frontend time (component loading) automatically.

🔍

SOQL & DML Analysis

Spots N+1 query patterns, governor limit usage, and slow operations with one-click drill-down.

🌲

Execution Tree

Visualize the full call stack — triggers → flows → future methods → callouts — as a navigable tree.

🔐

PII Scanner

Automatically flags emails, IDs, and other sensitive data in log output before you share files.

⚡

Live Connection

Connect to your org via OAuth or session token — stream debug logs in real time, re-run queries live.

📤

Export Reports

Generate PDF or HTML reports ready to drop into a Jira ticket or share with your team.

💡

Smart Recommendations

"Add recursion control to CaseTrigger" — auto-generated fixes based on detected patterns.

Installation

  1. Download BlackWidow-win-x64-Setup.exe above.
  2. Run it — no admin rights needed. Installs to %LocalAppData%\Black Widow.
  3. Launch from the Start Menu or Desktop shortcut.
  1. Download the macOS zip matching your chip:
    M1/M2/M3 → macos-arm64.zip  |  Intel → macos-x64.zip
  2. Unzip and drag BlackWidow to your Applications folder.
  3. First launch: right-click → Open to bypass the Gatekeeper warning (unsigned app).
  1. Download BlackWidow-linux-x64.tar.gz above.
  2. Extract and run:
tar -xzf BlackWidow-*-linux-x64.tar.gz -C ~/blackwidow
cd ~/blackwidow
./BlackWidow

No .NET installation required — all runtimes are bundled. Requires Windows 10 21H2+, macOS 12+, or Ubuntu 22.04+.
