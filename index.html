Local-first

“Why not just paste it into ChatGPT?”

Because in a real org you can’t. Production logs carry customer data, record IDs and org configuration, and most security teams already ban pasting them into an outside model. Black Widow does the work on your machine.

01

Analysis runs offline

Parsing, timelines, health scores, governor-limit math and recursion detection make zero network calls. Pull the cable — it still works.

02

AI is optional and yours

The plain-English explainer is off by default. When you turn it on, it uses your own key and sends a structured summary — never the raw log.

03

Org connection is direct

Monitoring talks to your org over standard Salesforce OAuth, straight from your machine. No middleware, no hosted proxy, nothing stored outside it.

FAQ

Questions people ask before installing.

Is the free tier really free, or a trial?

Free. Live org monitoring, log parsing, transaction grouping, phase detection, the Overview and Explain summaries, and AI analysis with your own key never expire and never need an account. Pro is a separate, optional layer — it adds the drill-down tabs, org log extraction and streaming, Shield analysis, exports and files over 10 MB.

Do I need Salesforce Shield or Event Monitoring?

No. The live checks — failed flows, async and scheduled jobs, Apex tests, logins, limits — run against standard objects in any org. If your org does have Event Monitoring, Pro adds analysis of those event log files too, and the app labels the ~24-hour delay on every card that uses them instead of pretending they’re live.

Does any org data leave my machine?

Raw debug logs never do. Analysis runs offline. Monitoring talks to your org over standard OAuth directly from your machine — there is no server in between. If you turn on AI, a structured summary — not the log — goes to the provider you chose with your own key. The complete list of network calls the app can make is on the Security & Privacy page.

Why does Windows show a SmartScreen warning?

The Windows installer isn’t code-signed yet, so Windows warns on first run. Click More info, then Run anyway. It installs to your user profile and needs no admin rights. The macOS builds are signed and notarized; Windows code-signing is on the roadmap.

How does the Pro trial work?

Start it from inside the app whenever you hit a Pro feature. Fourteen days, no card. If you buy and change your mind, there’s a 30-day money-back guarantee — details on the Security & Privacy page.

Will it decode Vlocity’s managed-package internals?

No tool can — Salesforce suppresses managed-package line detail for everyone. What Black Widow does give you is exactly how much SOQL, DML and CPU the vlocity_cmt namespace burned in the transaction and where in the timeline it happened, which is usually the question you actually have.
