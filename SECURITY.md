# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Older releases | ❌ — please upgrade |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Email: **victorfelisbino@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Expected response time: **48 hours**.

You will receive acknowledgement when the report is received and a follow-up once the issue has been investigated.
